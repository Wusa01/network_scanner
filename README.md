# Network Security Scanner

أداة Python تعليمية بسيطة تشبه نسخة مصغّرة من أدوات فحص الشبكات (مثل nmap)،
مبنية بالكامل باستخدام مكتبة `socket` القياسية دون أي اعتماديات خارجية.

## الميزات

- **اكتشاف الأجهزة (Host Discovery)**: فحص مدى شبكة كامل (CIDR) لمعرفة الأجهزة الحيّة (UP).
- **فحص المنافذ (Port Scanning)**: فحص TCP Connect Scan لمدى منافذ على جهاز واحد.
- **تحديد الخدمة (Service Detection)**: مطابقة رقم المنفذ بقاموس أكثر من 40 خدمة معروفة، مع Banner Grabbing اختياري.
- **Multithreading**: فحص متوازٍ للأجهزة/المنافذ عبر `ThreadPoolExecutor` لتسريع الفحص بشكل كبير.
- **Timeout قابل للتخصيص** لكل عملية اتصال/ping.
- **تصدير JSON** لحفظ النتائج بصيغة منظّمة.
- **Logging** كامل (رسائل INFO في الطرفية، وسجل تفصيلي DEBUG في `scanner.log`).
- **واجهة سطر أوامر (CLI)** مرنة عبر `argparse`.

## المتطلبات

- Python 3.10 أو أحدث (لاستخدام صيغ type hints مثل `list[int]`).
- نظام Linux مع توفر أمر `ping` في النظام (لوضع اكتشاف الأجهزة).
- لا حاجة لأي مكتبات خارجية إضافية (Standard Library فقط).

## طريقة الاستخدام

### 1. اكتشاف الأجهزة الحيّة في شبكة

```bash
python scanner.py 192.168.1.0/24
```

مثال للمخرجات:
```
192.168.1.1     UP
192.168.1.5     UP
192.168.1.10    UP
```

### 2. فحص منافذ جهاز واحد

```bash
python scanner.py 192.168.1.10 --ports 1-1000
```

مثال للمخرجات:
```
PORT    STATE     SERVICE           BANNER
22      OPEN      SSH               SSH-2.0-OpenSSH_8.9
80      OPEN      HTTP              HTTP/1.1 200 OK
443     OPEN      HTTPS
```

### خيارات إضافية

| الخيار | الوصف | الافتراضي |
|---|---|---|
| `--ports RANGE` | منافذ للفحص: `"80"`, `"1-1000"`, أو `"22,80,443"` | `1-1024` |
| `--timeout SEC` | مهلة كل محاولة اتصال/ping (بالثواني) | `1.0` |
| `--threads N` | أقصى عدد خيوط متوازية | `50` (أجهزة) / `200` (منافذ) |
| `--json FILE` | حفظ النتائج في ملف JSON | — |
| `--no-banner` | تعطيل قراءة الـ banner (فحص أسرع) | معطّل (banner مفعّل) |
| `--verbose` | عرض تفاصيل DEBUG في الطرفية | معطّل |

### أمثلة إضافية

```bash
# فحص منافذ محددة مع حفظ النتائج بصيغة JSON
python scanner.py 192.168.1.10 --ports 22,80,443 --json result.json

# اكتشاف أجهزة بمهلة أقصر وعدد خيوط أكبر مع تفاصيل كاملة
python scanner.py 192.168.1.0/24 --timeout 0.5 --threads 100 --verbose

# فحص سريع بدون banner grabbing
python scanner.py 192.168.1.10 --ports 1-65535 --no-banner --threads 500
```

## ملاحظات تقنية

- **TCP Connect Scan** وليس SYN Scan: لا يحتاج صلاحيات root، لكنه أبطأ قليلًا وأسهل اكتشافًا من أنظمة الحماية (IDS/Firewall) مقارنة بـ SYN scan.
- **اكتشاف الأجهزة** يعتمد على أمر `ping` النظامي عبر `subprocess` بدل raw sockets، لنفس سبب تجنّب صلاحيات root.
- عند تمرير `--ports` مع هدف شبكة كاملة (CIDR)، يتم تجاهله حاليًا مع رسالة تحذير (هذا الإصدار لا يدعم بعد دمج الاكتشاف + فحص المنافذ في أمر واحد لكل الأجهزة).

## إخلاء مسؤولية

هذه الأداة مخصصة **لأغراض تعليمية وفحص الأنظمة التي تملكها أو لديك إذن صريح بفحصها فقط**.
فحص شبكات أو أجهزة دون إذن قد يكون مخالفًا للقانون في بلدك.
